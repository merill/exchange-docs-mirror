# Hybrid deployment procedures | Microsoft Learn

Configuring and managing hybrid deployments are easier than ever with the latest improvements to the Hybrid Configuration wizard. You configure a hybrid deployment as the first step in either of the following scenarios:

- Long-term coexistence of your on-premises Exchange and Exchange Online organizations.
- Migration to the cloud.
