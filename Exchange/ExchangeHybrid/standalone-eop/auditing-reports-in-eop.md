# Auditing reports in the Built-in security add-on for on-premises mailboxes | Microsoft Learn

If you use the Built-in security add-on for on-premises mailboxes, the available cloud auditing reports can help you meet regulatory, compliance, and litigation requirements for your on-premises organization. Auditing reports identify changes to your configuration of the Built-in security add-on for on-premises mailboxes. These reports can help you troubleshoot configuration issues or find the cause of security-related or compliance-related problems.

For more information, see the following articles:

- [Search the audit log](/en-us/purview/audit-search)
- [Audit log activities](/en-us/purview/audit-log-activities)
