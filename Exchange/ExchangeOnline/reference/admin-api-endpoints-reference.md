# Endpoints reference | Microsoft Learn

Note

The features described in this article are currently in Preview, aren't available in all organizations, and are subject to change.

The following endpoints are available for the Exchange Online Admin API:

- [AcceptedDomain](admin-api-endpoints-accepted-domain)
- [DistributionGroupMember](admin-api-endpoints-distribution-group-member)
- [DynamicDistributionGroupMember](admin-api-endpoints-dynamic-distribution-group-member)
- [Mailbox](admin-api-endpoints-mailbox)
- [MailboxFolderPermission](admin-api-endpoints-mailbox-folder-permission)
- [OrganizationConfig](admin-api-endpoints-organization-config)

The Exchange Online Admin API provides a REST-based way to run specific PowerShell cmdlets, replacing legacy Exchange Web Services (EWS) scenarios. For more information, see [Overview of the Exchange Online Admin API](admin-api-overview).
