# Install or remove add-ins for Outlook for your Exchange Online organization in Exchange Online | Microsoft Learn

We recommend that you manage Office add-ins for your Exchange Online organization via Centralized Deployment in the Microsoft 365 admin center. For more information, see [Manage deployment of add-ins in the Microsoft 365 admin center](/en-us/microsoft-365/admin/manage/manage-deployment-of-add-ins).
