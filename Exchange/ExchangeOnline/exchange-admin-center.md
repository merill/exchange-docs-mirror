# Exchange admin center in Exchange Online | Microsoft Learn

The Exchange admin center (EAC) is a modern, web-based management console for managing Exchange Online. The design of the EAC in Exchange Online aligns with the overall Microsoft 365 admin experience. The EAC replaces the Exchange Control Panel (ECP) that was formerly used.

## Experience the EAC

You open the EAC at https://admin.cloud.microsoft/exchange#/homepage. [Role based access control (RBAC)](permissions-exo/permissions-exo) determines the features available to you in the EAC.

The following videos highlight the features capabilities of the EAC:

- **Personalized dashboard, reports, and insights**

    The EAC offers actionable insights and includes reports for mail flow, migration, and priority monitoring.
- **New navigation panel**

    The EAC includes a left navigation panel to make it easier to find the features.
- **Azure cloud shell support**

    Cloud Shell is a browser-accessible shell that provides a command-line experience built with Azure management tasks in mind. It enables administrators to choose a shell experience that best suits their working lifestyle.
- **Improved mailbox management**

    Recipient management is one of the most crucial tasks that administrators perform. The EAC now includes easier mailbox management.
- **Improved support for groups**

    The EAC enables you to create and manage four types of groups: Microsoft 365 Groups, distribution groups, mail-enabled security groups, and dynamic distribution groups.
- **Migration capabilities**

    The EAC supports various kinds of migrations, including cross-tenant migrations and automated Google Workspace (G-Suite) migrations.
